# Dos Bol

Двуязычный адаптивный React-сервис для профилактики школьного буллинга и безопасного обращения за поддержкой.

## Запуск

```bash
npm install
npm run dev
```

Production-проверка:

```bash
npm test
npm run build
```

## Демо-аккаунты

| Роль | Логин | Пароль |
|---|---|---|
| Ученик | `student` | `Student123!` |
| Учитель | `teacher` | `Teacher123!` |
| Психолог | `psychologist` | `Psycho123!` |
| Администратор школы / завуч | `admin` | `Admin123!` |
| Администратор сайта | `bolatbekovameruert@gmail.com` | `Meruert2026!` |

Логины, пароли, сессии и создание аккаунтов работают через серверные API и общую базу данных.

## Возможности ролей

- Ученик: безопасный чат, видеоуроки, тест о буллинге, база знаний и личный прогресс.
- Учитель: обзор своих классов, фиксация наблюдений, список учеников и материалы для классного часа.
- Психолог: приоритетные сигналы, инциденты, ученики риска, кейсы, встречи и аналитика.
- Администратор школы: агрегированная статистика, классы, пользователи и системные настройки без приватных заметок психолога.

Интерфейс поддерживает русский и казахский языки, светлую и тёмную темы, desktop, tablet и mobile.
